## About

I work on two things at once: **peer-reviewed research** on the security of emerging systems, and **hands-on security practice** — auditing real-world mobile apps, routers, and LLM agent tooling, then publishing what I learn on the [SPERIXLABS blog](https://sperixlabs.org/posts/).

- **Research** — 45 publications across IoT & network security, blockchain & 5G, AI & assistive technologies, and applied security audits of banking, streaming, and messaging platforms. [Read them →](https://sperixlabs.org/publication/)
- **Certifications** — ICSI CNSS Certified Network Security Specialist · EC-Council Certified Cybersecurity Technician · Certified SOC Analyst
- **Teaching** — Telecommunication Engineering, KNUST — from IoT security to advanced cryptography

## What I'm building

### AI × Security & LLM Agent Infrastructure

- **[manifold](https://github.com/jayluxferro/manifold)** — chain multiple LLM proxy services into a single transparent pipeline · [writeup](https://sperixlabs.org/post/2026/07/manifold-chaining-seven-proxy-layers-into-a-single-transparent-llm-pipeline/)
- **[llm-redactor](https://github.com/jayluxferro/llm-redactor)** — removes, masks, or transforms sensitive content before it leaves your device · [writeup](https://sperixlabs.org/post/2026/04/llm-redactor-what-leaves-your-prompt-when-you-talk-to-a-cloud-llm/)
- **[local-splitter](https://github.com/jayluxferro/local-splitter)** — local model as a triage layer in front of frontier cloud LLMs, cutting token costs · [writeup](https://sperixlabs.org/post/2026/04/local-splitter-cutting-cloud-llm-costs-by-putting-a-small-model-in-front/)
- **[resilient-write](https://github.com/jayluxferro/resilient-write)** / **[resilient-read](https://github.com/jayluxferro/resilient-read)** — MCP servers giving coding agents a fault-tolerant write surface and safe chunked reads of huge files
- **[hivemind](https://github.com/jayluxferro/hivemind)** — OS-inspired scheduler for concurrent LLM coding agents
- **[gen-pilot](https://github.com/jayluxferro/gen-pilot)** — context-aware generation planning and deferred document rendering for coding agents
- **[daedalus](https://github.com/jayluxferro/daedalus)** — container detonation, analysis & experimentation sandboxing · [writeup](https://sperixlabs.org/post/2026/07/daedalus-a-security-research-control-plane-for-apples-container-runtime/)
- **[burp-ollama](https://github.com/jayluxferro/burp-ollama)** — AI-powered security testing in Burp Suite with local Ollama models
- **[ida-pro-mcp](https://github.com/jayluxferro/ida-pro-mcp)** — bridges IDA Pro with language models over MCP
- **[ollama-forge](https://github.com/jayluxferro/ollama-forge)** — pull models from Hugging Face, convert them, add adapters, run them in Ollama
